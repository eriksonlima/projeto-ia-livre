# Specs

Fluxo Spec-Driven: **especificar → planejar → tasks → implementar → convergir**.

Para cada feature ou etapa não trivial:

1. Copie `_templates/` para `specs/<slug>/`
2. Preencha `spec.md`, `plan.md`, `tasks.md`
3. Implemente **uma task por fatia**
4. Atualize checkboxes em `tasks.md` e o `ROADMAP.md`

Não implemente código de produto sem spec aprovada (exceto ajuste óbvio).
