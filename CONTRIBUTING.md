# Contribuindo

## Fluxo

1. Leia `AGENTS.md` e `ROADMAP.md`.
2. Trabalho não trivial: crie/atualize a spec em `specs/<slug>/` antes de implementar.
3. Uma fatia por vez, alinhada à etapa `em_andamento`.
4. Rode o gate de verificação de `AGENTS.md`.
5. Abra PR com o template em `.github/PULL_REQUEST_TEMPLATE.md`.

## Commits e PRs com assistência de IA

Se um commit, PR ou comentário foi gerado ou substancialmente assistido por IA, declare no corpo:

- Ferramenta/agente e modelo (se conhecido)
- Extensão: rascunho, implementação, revisão, etc.
