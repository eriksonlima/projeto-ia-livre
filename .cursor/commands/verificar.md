# verificar

Rode o gate de verificação antes de declarar a fatia pronta.

1. Leia `AGENTS.md` → **Como verificar**.
2. Execute os comandos listados. Se não houver comando, cumpra o checklist do Pronto quando.
3. Relate o que passou, o que falhou e o que não foi verificado.
4. Sem evidência, a fatia **não** está pronta.
