# pr

Abra um pull request com evidência do gate.

1. Confirme que o gate passou (`/verificar`).
2. Siga o fluxo de PR das user rules (`gh`, HEREDOC, sem force push).
3. Use `.github/PULL_REQUEST_TEMPLATE.md`.
4. Inclua disclosure de IA se a mudança foi assistida.
5. Não abra PR com segredos no diff.
