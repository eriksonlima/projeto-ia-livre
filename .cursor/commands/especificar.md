# especificar

Crie ou atualize a spec da etapa/feature **sem implementar código de produto**.

1. Leia `ROADMAP.md` e a etapa `em_andamento`.
2. Crie `specs/<slug>/` a partir de `specs/_templates/` (ou peça ao subagente `especificador`).
3. Preencha `spec.md`, `plan.md` e `tasks.md`.
4. Atualize o campo `Spec:` da etapa no `ROADMAP.md`.
5. Pare. Não escreva código de aplicação nesta invocação.
