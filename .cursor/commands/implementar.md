# implementar

Implemente **uma** task da spec ativa / etapa `em_andamento`.

1. Leia `AGENTS.md`, `ROADMAP.md` e `specs/<slug>/tasks.md`.
2. Escolha a próxima task aberta. Declare a fatia (objetivo, fora de escopo, pronto quando).
3. Implemente só essa task.
4. Rode `/verificar` (gate de `AGENTS.md`).
5. Marque a task como feita e atualize o roadmap se a etapa terminou.
