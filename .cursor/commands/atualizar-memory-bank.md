# atualizar-memory-bank

Revise o Memory Bank enxuto **sem** reescrever docs/roadmap.

1. Leia `ROADMAP.md`, `docs/product-context.md`, `docs/architecture.md` e `AGENTS.md`.
2. Atualize `memory-bank/activeContext.md`: foco atual, mudanças recentes, próximo passo.
3. Atualize `memory-bank/progress.md`: o que funciona, bloqueios — apontando etapas do roadmap.
4. Confirme que `memory-bank/README.md` ainda aponta para as fontes estáveis.
5. Não copie product-context, architecture ou o roadmap inteiro para dentro de `memory-bank/`.
